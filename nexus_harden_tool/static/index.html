Each phase can use its own model. Pick a model file and this tool starts it when it's needed and stops it when it switches to another, so a run can go 9B → long-context → 27B unattended without them all having to fit in RAM at once. A server you started yourself (in the launcher) can be used too, but this tool can't unload it.
